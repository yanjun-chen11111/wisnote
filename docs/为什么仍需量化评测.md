# 用现成模型为什么仍需量化评测

## 一句话结论

> 模型的能力可以引用公开榜单，但"你的切块 + 你的解析 + 你的阈值 + 你的语料"这个组合的表现，
> 全世界只有你自己能量出来——而这正是论文里属于"你做的工作"的部分。

## 用现成模型确实可以省掉的那部分

嵌入模型**本身好不好**，不需要自己验证——bge-small-zh-v1.5 在公开中文榜单 **C-MTEB** 上
有官方测评成绩，论文直接引用即可：

> "本文选用在 C-MTEB 检索任务上表现优异的 BAAI/bge-small-zh-v1.5"

不需要复测模型内部能力，这就是"现成"的价值。

## 但量化评测量的不是模型，是你的系统决策

关键区别。看检索链条：

```
你的解析器 → 你的切块参数 → 现成模型 → 你的相似度阈值 → Top-K
   ↑            ↑                            ↑
 你写的        你定的                        你定的
```

bge 模型厂商**从没见过**你的这些决策组合：

| 你的决策 | 模型厂商测试过吗 | 出问题谁发现 |
|----------|:---:|:---:|
| 切块 500 字 + 50 重叠 | 没有 | 只有量化能发现 |
| PDF 用 blocks 模式解析 | 没有 | 只有量化能发现 |
| 中文课程笔记语料（术语、公式混排） | 只测过通用语料 | 只有量化能发现 |
| "无关问题 < 0.4 拒绝回答"这个阈值 | 没有 | 只有量化能发现 |

真实数据举例（本项目已实测）：

- "局部性原理"一题排到 **Top3 而非 Top1**——不量化永远不会知道，只会觉得"感觉挺好"；
- "股票行情"负例相似度 **0.381**，离阈值 0.4 只差 0.019——**阈值是否安全必须在
  自己语料上量出来**。换一批语料（如法律笔记），相似度分布完全不同，0.4 可能失效。

## 三个必须量化的硬理由

1. **答辩必问**："为什么切块选 500？""怎么证明检索有效？"——没有数字只能回答
   "感觉不错"，这是毕设答辩的重灾区；
2. **论文要求**：实验章节必须包含"指标 + 对比 + 分析"，没有量化数据没法写；
3. **工程回归**：后续接 Qwen、做界面、调参数，每次改动都可能悄悄弄坏检索——
   有了量化脚本，改完跑一遍就知道是否退化，不靠手感。

## 结论

- 模型选型 → 引用公开榜单（C-MTEB），省事且有依据；
- 系统效果 → 必须自己量化（gold set + Recall@K + MRR + 负例），无可替代。
