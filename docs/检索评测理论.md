# 检索评测理论（gold set / Recall / MRR / 负例）

## 一、为什么要量化

相似度 0.66 这个数字本身没有"对错"——它只是相对排序。
必须引入**外部标准**（人工标注）才能判断"找到的块是不是该找的块"。

## 二、验证分三层

### 第1层：负例测试（证明"不乱找"）

问一个与笔记完全无关的问题（如"今晚吃什么"），最高相似度应明显低（阈值取 **0.4**）。
若无关问题也能得 0.7，说明模型在"硬凑"，后面 AI 回答就会胡编。

### 第2层：Gold set 命中率（证明"找得到"）

人工标注 N 个问题，每个问题标上"正确答案里必须出现的关键词"。
示例（CSV 格式，分号分隔多个关键词）：

| 问题 | 判定关键词 |
|------|-----------|
| 死锁产生的必要条件是什么 | 互斥条件;环路等待;不剥夺条件 |
| TCP通过什么机制建立和释放连接 | 三次握手;四次挥手 |

问题分两类（category 列）：
- **literal（字面题）**：问题里含原文术语 → BM25 的主场；
- **paraphrase（改写题）**：口语化、同义表达，不含原文关键词 → 语义检索的优势场景。

### 第3层：指标计算（证明"找得准"）

- **Recall@K（命中率）** = 排名 ≤ K 的问题数 ÷ 总题数
  例：18 题里 17 题进了 Top-3 → Recall@3 = 94.4%
- **MRR（平均倒数排名）** = Σ(1/排名) ÷ 题数
  例：3 题排名 [1, 2, 5] → MRR = (1/1 + 1/2 + 1/5) ÷ 3 ≈ 0.567
  排得越靠前分越高，比命中率更能体现"排序质量"。

## 三、对照与消融

- **BM25 基线（对照方法）**：传统关键词检索，统计词频，"死锁"两个字必须出现才能得分，
  代表"没有语义理解的老方法"。论文用它衬托语义检索在改写题上的优势。
- **消融实验**：只改一个参数（如切块大小 300/500/800），其余不变，看指标变化，
  证明参数选择有依据。

## 四、结果怎么解读（诚实分析要点）

1. 语料太小时（几十个块），Top-5 ≈ 大半个库，两种方法都接近满分，区分度被压缩；
2. 中文分词后，改写题和原文常共享字符（"淘汰哪个**页面**"），BM25 不会完全失效；
3. 样本太少时 1 题的波动就是百分之几十，差异可能在噪声范围内；
4. **负例全过是硬结论**——证明检索没有把无关内容硬关联，是防幻觉的第一道闸门；
5. 语义检索的优势要在语料变大 + 问题更口语时才拉开差距。
