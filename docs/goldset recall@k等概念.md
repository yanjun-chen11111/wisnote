1为什么要量化
相似度 0.66 本身没有对错，只是相对排序。必须拿人工标注来对照，才能判断“找到的块是不是该找的块”。

2Gold Set 是什么、干嘛用
人工标注的“问题 → 正确答案 chunk / 必须出现的关键词”。它是标准答案，用来：

·算 Recall@K、MRR、NDCG

·调负例阈值

·对比不同模型 / 版本

·定位错误、做回归测试和上线验收

3相似度公式 ≠ 评估指标

余弦相似度、点积、BM25 等：只是“尺子”，产生分数和排序。

Recall@K、MRR、NDCG：才是“裁判”，判断排序结果好不好。
0.66 好不好，取决于你的数据分布，不能单独下结论。

3三层验证框架

负例测试：无关问题不应得高分，证明“不乱找”。阈值如 0.4 要在自己数据上验证。

Gold Set 命中率：正确答案有没有进 Top-K，证明“找得到”。

指标计算：Recall@K、MRR、NDCG，证明“找得准、排得好”。

4三个指标各管什么

Recall@K：正确答案有没有进前 K 个？管“找全”。

MRR：第一个正确结果排多靠前？管“最佳答案靠前”。

NDCG：多个相关结果、相关度不同时，整体排序质量如何？管“整体排序”。
