# 公开榜单（C-MTEB）是怎么测的

> 与《量化评测实施指南》是同一套方法论，只是规模和标准化程度不同。

## C-MTEB 是什么

Chinese Massive Text Embedding Benchmark，BAAI 出品，
目前中文嵌入模型最权威的榜单，bge 系列模型就出自这个团队。
35 个数据集，7 类任务（检索、语义相似度 STS、重排、成对分类、聚类、分类、摘要）。

## ① 标注数据集（他们的 gold set）从哪来

真实使用场景的"查询-段落"对：

| 数据集 | 来源 |
|--------|------|
| T2Retrieval | 真实搜索引擎日志（用户查询 + 点击的网页段落），人工标注相关性 |
| DuRetrieval | 百度搜索数据 |
| CMEdQA | 医疗问答社区的真实提问与医生回答 |
| MMarcoR | 从英文 MS MARCO 翻译而来 |

每条样本 = 1 个查询 + 1 个正确段落 + **成千上万个"容易混淆的错误段落"**
（专门挖掘的 hard negatives，让题目有区分度）。

## ② 测评流程

```
几百万个段落全部向量化入库
        ↓
每个查询向量化 → Top-K 检索
        ↓
看正确段落排第几 → 算指标
        ↓
汇总成分数
```

与本项目指南的"逐题检索记排名 → 计算指标"完全同构，只是自动化、大规模。

## ③ 指标

| 指标 | 含义 |
|------|------|
| Recall@K | 正确段落进 Top-K 的比例 |
| MRR@10 | 平均倒数排名（Top-10 内） |
| nDCG@10 | 正确答案有多个且分重要性级别时用：排第1名得满分，第10名按对数衰减打折——比 Recall 更细地反映排序质量 |

## ④ 分数汇总

35 个数据集 → 按任务类型分组 → 每类算平均分 → 加权平均 → 榜单上的总分。

## 与本项目自测的关系

| | C-MTEB（工业级） | 本项目量化评测（毕设级） |
|---|---|---|
| gold set | 几百万条，官方标准化 | 30~50 题，自己标注 |
| 语料 | 通用语料（网页/问答） | 自己的课程笔记 |
| 指标 | Recall@K、nDCG、MRR | Recall@K、MRR |
| 测的对象 | 模型本身 | "切块+解析+阈值+语料"组合 |
| 结论用途 | 选模型（论文引用即可） | 验证系统（论文实验章节） |

**配套使用**：榜单证明 bge 模型"底子好"，自己的评测证明"底子好的模型在我的系统里也好使"。
