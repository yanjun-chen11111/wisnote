# AI 知识点讲解功能设计（WisNote）

> 状态：已实现并实测（2026-10-12，含 Ollama 真实生成路径）。本文档以实测行为为准。

## 功能定位

「AI 知识点讲解」页用**两个正交的选择器**控制一次讲解：

- **讲解模式**（怎么讲）：决定大模型的教学风格
- **讲解依据**（用什么讲）：决定内容来自哪里——笔记、模型自身知识、还是两者按条件切换

两者自由组合：如「考点分析 × 只用笔记」= 严格基于自己笔记的考点梳理。

## 选择器①：讲解模式（四档）

| 模式 | key | 风格 | 适用 |
|---|---|---|---|
| 通俗讲解 | `plain` | 一句话定义 → 生活类比 → 2~3 个关键要点 | 零基础入门 |
| 分步讲解 | `steps` | 流程概览 → 1、2、3 逐步展开（做什么+为什么）→ 依赖关系总结 | 操作类/流程类知识 |
| 问答引导 | `socratic` | 先抛 2~3 个引导问题 → 逐个解答 → 小结 + 进阶思考题 | 启发式自学 |
| 考点分析 | `exam` | 常考形式 → 核心考点清单 → 易错点 → 答题得分技巧 | 复习备考 |

四种模式共用同一个模型（Ollama Qwen3-1.7B），仅切换系统提示词与任务描述（单模型 Prompt 路由）。

## 选择器②：讲解依据（三档）

| 选项 | key | 行为 | 什么时候用 |
|---|---|---|---|
| **笔记优先**（默认） | `auto` | 检索到相关笔记 → 结合笔记讲，标注 [1][2] 来源、可溯源；未检索到 → 用模型知识讲，开头标注"ℹ️ 笔记中未找到相关内容，以下基于大模型通用知识讲解（无溯源）" | 日常首选 |
| **只用笔记** | `notes` | 笔记里有 → 严格依据笔记讲（同上可溯源）；笔记里没有 → **不调用模型**，直接说明"笔记中关于「XX」的内容不足，无法充分讲解。请先补充相关笔记资料。" | 演示"严格依据资料"、保证答案可信可溯源 |
| **只用模型知识** | `llm` | 完全不查笔记，纯大模型讲解（任何主题都能讲，无溯源） | 讲笔记之外的通用知识 |

### 判定流程（`stream_explain`）

```
source == "llm" ──────────────→ 跳过检索，纯模型讲解（无来源）

否则：向量语义检索（top_k=5）
  └─ 最高相似度 ≥ 0.30 ？
       ├─ 是 → 结合笔记讲（grounded：只用笔记片段、标来源编号、引用计数 +1）
       └─ 否 → source=="notes"：直接说明资料不足（不调模型）
               source=="auto" ：降级为模型知识讲解，带 ℹ️ 前缀
```

关键参数：
- **相似度阈值 0.30**（`min_similarity`）：低于它视为"笔记里没有"，防止拿不相关片段硬凑
- **检索方式**：纯向量语义检索（ChromaDB），`top_k=5`；召回后由模型讲解，不是直接返回原文

### 两套提示词规则

- **grounded（依据笔记）**：只能依据笔记片段讲解、不得引入外部知识或编造；引用处标 [n]；信息不足时明说"笔记中相关内容有限"，不猜
- **free（模型知识）**：基于模型自身知识讲解，准确、分点；没把握的内容要说明"这部分我不确定"，不编造具体数据

## 配套行为

- **溯源展示**：回答下方展开"引用来源"（文档标题/页码/相似度/片段）；来源是 **PDF** 可看原文高亮截图，来源是**图片**直接展示原图
- **引用计数**：笔记被讲解引用一次，该资料 `ref_count` +1（用于热门统计）
- **会话存档**：讲解自动记入当前聊天会话（含来源），可在「聊天记录」页回看
- **流式输出**：逐字呈现，纯 CPU 首次约 60~120 秒

## 已知边界

- **CLI 差异**：`scripts/chat_cli.py` 使用旧版非流式 `explain()`，**没有依据选择**，行为≈「只用笔记」（无资料即拒答）。网页版为准
- `auto` 档降级由**最高相似度阈值**判定，主题换了说法但笔记里其实有相关内容、相似度却低于 0.30 时，会误判为"未找到"而走模型知识（属可接受误差）
- 讲解内容**不会**自动写回笔记，只存聊天记录

## 涉及模块

- `ui/app.py`：`page_explain`（两个选择器 UI，`source` 默认 `auto`）
- `wisnote/explain.py`：`EXPLAIN_MODES`（四模式）、`stream_explain`（依据三档路由）、`build_messages`（两套规则提示词）
- `wisnote/search.py`：`search_notes`（向量检索 + 标题回填）
- `wisnote/rag.py`：`build_context` / `build_sources`（上下文组装与溯源信息）
