远程桌面连接（Remote Desktop Connection）是微软从Windows 2000 Server开始提供的组件，但是并不是默认安装的。在Windows XP和Windows Server 2003中，微软将此组件的启动方法进行了改革，只需要通过简单的设置就可以开启远程桌面连接功能。

== 功能 ==
当某台联网的计算机开启了远程桌面连接功能后我们就可以在网络的另一端控制这台计算机了，通过远程桌面功能我们就可以操作这台计算机。所有的操作就像在自己的计算机上操作一样。通过该功能，网络管理员可以在家里轻松安全的控制单位的服务器。由于该组件是 Windows 系统内置的，所以比其他第三方远程控制软件更加方便灵活。

== 开启远程连接 ==

=== Windows XP/Windows Server 2003 ===
在桌面“我的电脑”上点鼠标右键，选择“属性”。
在弹出的系统属性窗口中选择“远程”标签。
在远程标签中找到“远程桌面”，在“启用这台计算机上的远程桌面”前打上对勾后确定即可完成远程桌面连接功能的启用。

== Windows Vista及以后版本 ==
在桌面 “计算机”上点击鼠标右键,选择“属性”。
在弹出的系统属性中选择窗口左侧的“远程设置”。
在远程标签在远程标签中找到“远程桌面”，在“允许远程连接到此计算机”前打上对勾后确定即可完成。

== 连接远程计算机 ==
通过任务栏的“开始->程序->附件->远程桌面连接”（Windows 10 Build 14393为开始->程序->远程桌面连接），或者用“Windows+R”组合键调出“运行”，输入“mstsc”确定，输入开启了远程桌面的计算机的IP地址。如果远程计算机在内网里没有独立的公网IP地址，则需要做端口映射后才能连接。

== 连接端口 ==
远程桌面连接采用3389端口，除非需要，否则这个端口最好不要开启，因为开放135端口的计算机越来越少，黑客就希望利用3389端口来入侵计算机。
关闭3389端口的方法：
（1）通过命令提示符（即CMD）关闭：
通过任务栏的“开始->程序->附件->命令提示符”（Windows 10 Build 14393为开始->程序->命令提示符），或者用“Windows+R”组合键调出“运行”，输入“cmd”确定，输入“netstat -ano |find "3389"”。（注意：不包括最外面的双引号，所有输入命令提示符的符号均为英文符号，不能有中文符号，注意空格）
（2）修改注册表关闭
“Windows+R”组合键调出“运行”，输入“regedit”打开注册表编辑器，分别打开以下两处并修改：
第一处：[HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\Wds\rdpwd\Tds\tcp]找到PortNumber值，默认是3389，选择十进制，改成你所希望的端口（范围在1024到65535，而且不能冲突）
第二处：[HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp]找到PortNumber值，默认是3389，选择十进制，改成你所希望的端口（范围在1024到65535，而且不能冲突）
