== 开始之前 ==
必备：一张Windows XP安装光盘和一台CD-ROM或DVD-ROM。找到Windows XP 产品密钥，它可能位于您购买的Windows xp安装光盘包装内
请备份要保留的所有文件，以防万一。可以将它们复制到软盘、可移动驱动器或 CD，如果您联网的话，也可以将其复制到网络文件夹。您可以直接复制这些文件，也可以使用大多数 Windows 版本附带的备份向导。备份向导位于“开始”菜单上的“附件”\“系统工具”文件夹中。
注意：不能在 Windows XP 中还原那些通过使用 Windows 95、Windows 98 或 Windows Millennium Edition 中的 Msbackup 工具创建的备份。
重启，进入BIOS设置（通常按F1、F2、F8、F10、DEL键，因不同BIOS而异），找到类似“First Boot”（第一读取）字样的选项，并进入；从列表中选择你的CD-ROM或DVD-ROM（该选项应该含有“CD”或“DVD”等字样）；找到并选择 “保存并重新启动(Save and Restart)”（或“保存并退出”(Save and Exit)，通常按F10键），在询问是否保存设置时选择“Y”（是）。（建议你重新启动计算机之前，先打开光驱并放入Windows XP安装光盘，因为已设定系统第一读取的是光盘，迟了放入光盘可能过了检测画面，此时则要重新启动）
确定所需的安装类型
基本上有三种不同类型的安装：升级、全新安装和多重引导安装。

升级。这是安装 Windows XP 的最简单方法。如果您运行的是以前版本的 Windows，那么我们建议您使用此方法。在进行升级时，现有的操作系统将替换为 Windows XP，但是您的数据和多数用户设置应当不会受到影响。（最好坚持在开始之前备份文件，以防万一。）
可以从 Windows 98、Windows 98 Second Edition、Windows Millennium Edition、Windows NT Workstation 4 (Service Pack 6) 或 Windows 2000 Professional 进行升级。

注意：Windows 2000 只能升级到 Windows XP Professional.
全新安装。它需要的工作比升级多一些。全新安装方法是在不干扰现有安装的情况下，在另一个驱动器或分区上安装 Windows XP，或者您也可以选择清除硬盘驱动器上的所有内容，以便从头开始安装。在执行全新安装之前一定要备份文件！在全新安装过程中，还可以对硬盘驱动器进行分区和格式化。最好在安装过程中进行分区和格式化，而不要提前做
多重引导安装。此方法是这三种方法中最难的一种，它从全新安装过程变化而来，允许您在一台计算机上运行多个操作系统。例如，可以同时安装 Windows XP 和 Windows 98。要从一个操作系统切换到另一个，可以重新启动计算机，并从计算机启动时出现的菜单中选择一个操作系统。这听起来很棒，但是除非您是高级计算机用户，否则不要尝试这样做。

== 开始安装 ==
将Windows XP 安装光盘插入到CD驱动器中。

注意：确保计算机可以从 CD 启动。如果计算机不能从 CD 启动，那么请按照下面“将计算机配置为从 CD 启动”的部分中的步骤进行操作，或者参阅“如何从命令提示符安装 Windows？”部分。
若已设置“First Boot”（第一读取）为光驱，并已插入Windows XP安装盘，将有以下画面，在画面出现后5秒内按任何键进入安装程序，否则不安装：

注意：密切注意这一点，此消息很容易错过。如果启动了当前的操作系统，则说明您已经错过了从 CD 启动的机会。请重新启动计算机然后再试一次。
安装程序检测硬件，等待约30秒：

在屏幕的底部会闪烁一些消息。这些消息只有在特殊情况（如安装特定的硬件访问层 (HAL) 或加载小型计算机系统接口 (SCSI) 驱动程序）下才显得重要。大多数用户可以忽略它们。

选择安装模式，立即安装按ENTER，修复控制台按R，退出按F3：

Windows XP协议，若同意，按F8；若不同意，按ESC，不同意表示不安装；往下翻页，按Page Down：
如果您现在安装的是带有Service Pack 的 Windows XP 这里的许可协议可能有所不同.
如果您的 Windows CD 是升级 CD，那么在接受协议之后，您需要插入以前版本的操作系统 CD，以便验证以前的版本是否能够升级到 Windows XP。

要点！如果您使用原始设备制造商（又称作 OEM）提供的恢复 CD，那么有可能出现该 CD 不被接受的情况。如果 OEM 恢复 CD 未被接受为有效媒体，那么必须使用 OEM 恢复 CD 来还原以前版本的 Windows。要了解有关使用 OEM 恢复媒体还原系统的详细信息，请与计算机制造商联系。

选择系统安装位置；用上下键选择，ENTER确认，按C则在未分区的位置上创建一个分区，按D则删除分区（要格式化），F3退出：

选择的磁盘要进行格式化，在某些情况下，安装盘不需要格式化；用户可以选择快速（Quick）的格式化模式；选择文件系统FAT或NTFS；用上下键选择，ENTER确认，ESC返回：
对于大多数配置，NTFS 是实现安全性和灵活性的绝佳选择。但是，如果您打算安装多重引导配置，并访问使用旧操作系统（如 Windows 95、Windows 98 或 Windows Millennium Edition）的驱动器上的数据，那么请选择 FAT。
当您格式化某个卷时，该卷上的文件将被删除，并且硬盘将经过扫描以查看是否存在坏扇区。在对卷进行格式化时，大部分时间都用在扫描磁盘上。如果您选择“快速”格式化选项，那么该分区上的文件将被删除，但是磁盘将不会经过检查坏扇区的扫描。只有在以前曾经格式化过该硬盘，并且您确信该硬盘未损坏时，才应使用此选项。
注意：在 Windows XP 安装过程中，如果所选分区是新分区，那么“保持现有文件系统”选项将不可用。对于大小小于或等于 2 GB 的分区，安装程序使用 FAT（又被称作 FAT16）文件系统。对于超过 2 GB 但是小于 32 GB 的分区，安装程序使用 FAT32 文件系统。对于超过 32 GB 的分区，安装程序使用 NTFS。
注意：如果您已经删除并创建了一个新系统分区，但是要在另一个分区上安装 Windows XP，那么此时将提示您同时为系统分区和启动分区选择文件系统。

安装程序完成后，将 CD 从 CD-ROM 驱动器中弹出。

== 執行其他與安裝有關的任務 ==

=== 如何從命令提示符安裝 Windows？ ===
如果您的計算機不從CD 啟動，那麼仍可以使用Windows XP 安裝軟盤啟動安裝程序。在安裝過程中，系統將提示您插入Windows XP CD。有關詳細信息，請參閱“創建啟動盤”。
另外，如果您有Windows 98 或Windows Millennium Edition 啟動盤，則可以使用Windows 98 或Windows Millennium Edition 啟動盤啟動計算機，然後運行Windows XP CD 上i386 文件夾中的Winnt.exe。
Smartdrv.exe 工具可以縮短將文件從CD 複製到硬盤驅動器的過程所需要的時間。要使用Smartdrv.exe 工具，請確保Smartdrv.exe 文件位於啟動盤上。
如果沒有Smartdrv.exe，那麼文件複製過程所需的時間會相當長，但是如果您能耐心等待，安裝仍能成功完成。請查找下列各項是否存在於啟動盤上的以下文件中；如果尚不存
在出現DOS 提示符（類似C:>）時，參照圖示操作。

鍵入Windows XP CD 所在驅動器的位置(如D:)然後按Enter

鍵入 cd I386,然後按Enter

鍵入winnt 開始安裝

在安裝開始時，按照屏幕上的提示操作。

== 安裝程序疑難解答 ==

=== 常規疑難解答 ===
如果您在運行安裝程序時遇到問題，請退出安裝程序，然後從Windows XP CD 運行“升級顧問”。下面是操作方法：

將Windows XP CD 插入到CD-ROM ​​驅動器中。
在出現“歡迎使用”菜單時，單擊“檢查系統兼容性”。
單擊“自動檢查我的系統”。
“升級顧問”將查看是否存在不兼容的硬件和軟件，如果檢測到的話，刪除或卸載它們，然後再次運行安裝程序。
如果“升級顧問”找不到問題，您還可以全新啟動計算機，然後再次運行安裝程序。全新啟動疑難解答方法只是一種去除可能導致問題的變量的方法。

==== 在Windows Millennium Edition 中執行全新啟動疑難解答 ====
單擊“開始”、“運行”，在“打開”框中鍵入msconfig，然後單擊“確定”。
在“常規”選項卡上，單擊“選擇性啟動”。
清除“選擇性啟動”下的所有復選框。
在“啟動”選項卡上，選中“*StateMgr”複選框（僅限Windows Millennium Edition），然後單擊“確定”。
提示重新啟動計算機時，單擊“是”。
在計算機重新啟動之後，單擊“開始”、“運行”，在“打開”框中鍵入msconfig，然後單擊“確定”。
要點：仔細查看“常規”選項卡，確保“選擇性啟動”下的複選框被清除。如果未選中任何復選框，請繼續執行下一步。如果您看到被禁用或者灰色的複選框，那麼說明您的計算機不是真正的全新啟動，您可能需要向影響Msconfig 的程序的製造商尋求幫助。
在確認您的計算機是全新啟動之後，嘗試再次運行Windows XP 安裝程序。

==== 從全新啟動狀態返回 ====
單擊“開始”、“運行”，在“打開”框中鍵入msconfig，然後單擊“確定”。
在“常規”選項卡上，單擊“正常啟動”，然後單擊“確定”。
當提示重新啟動計算機時，單擊“是”。

=== 安裝過程中出現文件複製錯誤 ===
假設安裝程序在文件複製過程中停止，而且您看到類似如下內容的消息：

下面是此問題一些可能的原因和解決方案：

Windows XP CD 可能已損壞。請用軟布清潔該CD，將其插入到CD 驅動器中，然後單擊“確定”。
CD 驅動器工作不正常，或者CD 可能振動得太厲害，要解決此問題，請查詢硬件文檔，或者與CD 驅動器的製造商聯繫。
如果您使用多個CD 驅動器，那麼計算機可能嘗試在錯誤的驅動器上查找文件。如果您的硬件具有禁用未在使用的CD 驅動器的功能，那麼請禁用未在使用的CD 驅動器。
 注意：要在Windows 95 中禁用某個設備，請右鍵單擊“我的電腦”，單擊“屬性”，打開“設備管理器”，然後清除“原始配置（當前）”
 。在Windows 98 和Windows Millennium Edition 中，應在“設備管理器”中選中“在此硬件配置文件中禁用”複選框。
如果需要的話，請在升級到Windows XP 之後重新啟用此設備。

計算機上染有病毒。運行病毒掃描程序來檢查您的系統，並確定必要的修復。
:注意：如果在安裝過程中遇到問題，則可以使用Windows Memory Diagnostic 工具來測試計算機的隨機存取存儲器(RAM)。此工具有助於確定安裝問題是否是由失敗的硬件（如RAM 或主板上的內存系統）引起的。要使用此工具，請按照Windows Memory Diagnostic 網站上的說明進行操作。

如果您可以排除上面列出的所有原因，但仍然收到錯誤消息，那麼請將i386 文件夾從CD 驅動器複製到本地硬盤，然後嘗試從硬盤運行安裝程序。
:注意：在Windows Millennium Edition 中的初始啟動菜單上沒有啟動至命令提示符的選項。但是，您可以啟動到啟動軟盤，然後鍵入C:並按Enter 訪問硬盤驅動器，但前提是啟動盤使用與硬盤相同的文件系統。

=== 計算機掛起或者停止響應並顯示黑屏 ===
當您嘗試升級到Windows XP 時，您的計算機可能停止響應（掛起），並可能顯示黑屏。這通常是由與Windows XP 不兼容的硬件或軟件造成的。
注意：在開始安裝之前，應當將系統的硬件與硬件兼容列表(HAL) 進行比較。還可以在Windows 目錄中的設備製造商網站上查找有關每個計算機設備（如打印機、掃描儀等）的信息：
如果在安裝過程中，計算機停止響應並顯示黑屏，請執行下列步驟：

在黑屏狀態下等待10 分鐘，檢查計算機會不會繼續執行安裝過程。觀察硬盤驅動器的指示燈，看是否有任何磁盤活動。安裝程序可能會自行解決此問題。
重新啟動計算機，看它是否在安裝過程中的同一位置上再次停止。有時，安裝程序會比上次停止響應時的位置前進一些。如果出現這種情況，請多次重新啟動計算機，安裝程序可能能夠完成。
如果第1 步和第2 步不奏效，那麼要還原到以前版本的操作系統或沒有操作系統，請重新啟動計算機，並選擇“取消Windows XP 安裝程序”選項。如果在重新啟動計算機時沒有“取消Windows XP 安裝程序”選項，那麼請參閱第5 步。
在還原到以前版本的操作系統之後，請卸載所有的病毒防護程序，卸載所有的啟動管理器程序（如GoBack），然後執行計算機的全新啟動。
如果升級再次失敗，那麼可能存在硬件不兼容的問題。您可以嘗試禁用 ACPI 功能。要執行此操作，請在計算機重新啟動時，等待出現按F6 以安裝SCSI 驅動程序這一選項。在該屏幕上，按 F7（而非 F6）。
如果安裝程序仍停止響應，那麼請禁用任何不必要的硬件。移除任何USB 設備，移除或禁用網卡、聲卡和串行卡，然後重新啟動安裝程序。
如果仍然接到此錯誤消息，那麼可能需要刷新（更新）主板上的BIOS。有關如何刷新BIOS 的信息，請諮詢計算機的製造商或者查詢主板的網站。
警告：除非您是高級用戶，否則不要嘗試刷新BIOS。錯誤地執行此操作可能會導致計算機無法使用。

如果BIOS 更新還不能解決此問題或者您無法獲得計算機的更新BIOS 版本，那麼可能需要安裝具有標準PC 硬件抽象層(HAL) 的Windows XP。要執行此操作，請在安裝程序第一次重新啟動計算機之後提示您按F6 時，按下F7（而非F6）。

=== 對其他錯誤進行疑難解答： ===
注意：如果您在安裝過程中遇到問題，那麼可以使用Windows 內存診斷工具來測試計算機的隨機存取存儲器(RAM)。此工具有助於確定安裝問題是否是由失敗的硬件（如RAM 或主板上的內存系統）引起的。要使用此工具，請按照Windows Memory Diagnostic 網站上的說明進行操作。

==== 在升級到Windows XP 之後，某個程序或設備不工作。 ====
首先，嘗試重新安裝該程序或設備。如果這不能解決問題，那麼請諮詢製造商，查看是否有針對Windows XP 而設計的軟件或硬件的新版本。如果這是舊程序，那麼請在“Windows 幫助和支持”中搜索單詞“兼容性”，查看有關運行“程序兼容性嚮導”的說明。

==== 消息：NTLDR is missing ====
如果您在安裝開始時選擇更新文件，那麼此問題將會自動得到修復。
要解決此問題，需要更正FAT32 BPB 中的頭（邊）值，使Windows XP能夠繼續啟動。重寫Windows 95、Windows 98 或Windows Millennium Edition 的啟動代碼以更新此值。為此，按照下列步驟操作：

通過包含Sys.com 文件的Windows 95、Windows 98 或Windows Millennium Edition 啟動盤重新啟動計算機。 （默認情況下包括此文件。）
在系統驅動器的根目錄中製作Msdos.sys 文件的備份副本。
鍵入以下命令
 attrib -h -r -s c:\msdos.sys
 rename msdos.sys *.ysy

在命令提示符處，鍵入sys c: 以便用準確的BPB 信息重寫Windows 95、Windows 98 或Windows Millennium Edition 的啟動代碼。如果此命令運行成功，請轉到下一步驟。
如果您使用Windows Millennium Edition 啟動盤，並收到以下錯誤信息
 Cannot find the system file in the standard locations on drive C:
則可能是因為已經刪除了Windows Millennium Edition 安裝程序中的一個或多個文件,按照下面的步驟將正確的文件放置到驅動器上，使sys 命令可以找到它們：

鍵入下面的命令。在鍵入每個命令後按 Enter：
 c:
 cd\windows

如果將Windows 安裝到與Windows 文件夾不同的文件夾中，請相應地調整命令。
鍵入以下命令嘗試切換到Command 文件夾：
 cd command

如果您收到找不到路徑的錯誤信息，請鍵入以下命令創建Command 文件夾，然後再次運行cd command 命令：
 md command

鍵入以下命令切換到 EBD 文件夾：
 cd ebd

如果您沒有收到找不到路徑的錯誤信息，請鍵入以下命令創建EBD 文件夾，然後重複cd ebd 命令：
 md ebd

在EBD 文件夾中，使用以下命令複製硬盤根目錄下的Io.sys 文件，並將Io.sys 文件重命名為Winboot.sys：
 attrib -s -h -r c:\io.sys
 copy c:\io.sys winboot.sys
Winboot.sys 是 Sys.com 需要的文件。

切換回驅動器A，然後鍵入以下命令：
 a:
 sys c:

鍵入以下命令恢復原始的Msdos.sys 文件。在鍵入每個命令後按 Enter：
 attrib -s -h -r c:\msdos.sys
 copy c:\msdos.ysy c:\msdos.sys

按 Y 覆蓋現有的 Msdos.sys 文件。會收到文件被改寫的“1 FILE(S) COPIED”確認。
將計算機重新啟動到Windows 95、Windows 98 或Windows Millennium Edition，然後嘗試重新安裝或升級到Windows XP。
注意：也可以在運行sys c: 命令後，啟動到故障恢復控制台，然後使用fixboot 命令重寫Windows XP 啟動代碼。使用此過程，原始安裝會正常繼續。

==== 消息：Error 127 or error code fffffdf0 in catroot2 folder ====
重命名Windows\System\Catroot2 文件夾並再次運行安裝程序。此問題已經在動態更新1.3 中得到修復。

==== 安裝程序在“正在完成設置”階段掛起。 ====
此錯誤通常是由病毒防護軟件導致的。請取消安裝，關閉病毒防護軟件，然後再次啟動安裝程序。 （或者，如果您在安裝開始時選擇更新文件，那麼此問題將會自動得到修復。）

=== 創建啟動盤 ===
啟動盤是一個或一組軟盤，允許您在不使用Windows 的情況下啟動計算機。在執行某些類型的疑難解答（如上方修復NTLDR）以及Windows 的全新安裝時，擁有安裝盤會非常有幫助。
您可以下載一個程序來創建六張Windows XP 安裝啟動軟盤，這些軟盤中包含訪問CD-ROM ​​驅動器以及啟動安裝過程所必需的文件和驅動程序。
但是，建議您不要創建啟動盤，而是從Windows XP CD 啟動計算機來啟動安裝程序。如果您的計算機還不能這樣做（大多數較新的計算機都可以），那麼請參閱標題為“將計算機配置為從CD 啟動”的部分以獲得詳細信息。如果您的計算機不支持從CD 啟動，那麼可以下載一個用於創建啟動盤的文件。

當您下載安裝磁盤時，下載文件中只包含一個較大的程序文件。當您運行下載的文件時，它將多個文件提取到多張軟盤中。您將看到如下提示：
 This program creates the Setup boot disks for Microsoft Windows XP.
 To create these disks, you need to provide 6 blank, formatted, high-density disks.
 Please specify the floppy drive to copy the images to.
 （這個程序製作Windows Xp 啟動盤，需要6張空白軟盤）

鍵入軟盤驅動器的驅動器號（通常是驅動器A）。在鍵入軟盤驅動器的驅動器號之後，您將看到如下提示：
 Insert one of these disks into drive <drive letter>:.This disk will become the Windows XP Setup Boot Disk.
 Press any key when you are ready.
(插入第一張空白軟盤，在你準備好後按下任意鍵）

當您按任意鍵時，下載的文件將開始提取並複製文件。繼續按照提示插入空白磁盤，直到創建了全部六張磁盤。如果創建過程被中斷，您必須再次運行下載的程序文件來創建全部六張磁盤。
用該程序指定的編號對每張磁盤進行標記(因為在安裝過程中，必須按照正確的順序使用這些磁盤。)
在創建了全部六張磁盤之後，將第一張磁盤插入軟盤驅動器中，然後重新啟動計算機。
請注意，計算機必須被配置為從軟盤驅動器啟動。大多數計算機都可以自動這樣做，但是，在某些情況下，您可能需要修改計算機的BIOS 設置，使其從軟盤驅動器啟動。有關修改計算機BIOS 設置的信息，請參閱標題為“將計算機配置為從CD 啟動”的部分。

當您重新啟動計算機時，安裝過程將開始。按照提示插入每張軟盤。隨後，系統將提示您插入Windows XP CD 以完成安裝。

=== 將計算機配置為從 CD 啟動 ===
一些計算機如果在CD-ROM ​​驅動器中檢測到可啟動的CD，那麼可能會自動提供從CD 啟動的選項。如果是這種情況，那麼在CD-ROM ​​驅動器中有可啟動CD 的情況下啟動計算機時，您將看到“Press any key to boot from CD”消息。若情況並非如此，您可以使用計算機BIOS（基本輸入/輸出系統）的設置程序，將計算機設置為從CD 啟動。
下面是操作方法：

當您首次啟動計算機時，請留意一條告訴您按某個鍵進入設置程序的簡短消息。例如，一些計算機將顯示“Press DELETE to enter setup”消息。
如果您的計算機不提供類似的消息，那麼請嘗試在啟動過程中按下列常用鍵：
Delete
F1
F2
F3，隨後按 F2
F10
Ctrl+Alt+Esc
Ctrl+Alt+S
Esc
如果在啟動過程中出現圖形，那麼按Esc 鍵通常會使圖形消失，以便您可以看到用於進入BIOS 設置的正確鍵。
當您看到該消息時，迅速按下所指示的鍵。您將進入一個類似於DOS ​​的程序，該程序由一個或多個屏幕組成。在該程序中，您有可能無法使用鼠標。不同計算機的BIOS 程序差別很大，但是請查找一個名為“Boot order”（啟動順序）或類似內容的選項。
將啟動順序設置為先從CD 啟動，再從硬盤驅動器啟動。

== 安裝多重引導系統 ==
可以在計算機上安裝多個操作系統，並在每次啟動計算機時選擇要使用的操作系統。這被稱作雙重引導或多重引導配置。這一部分介紹如何將Windows XP 和下列操作系統設置為多重引導系統：
這看起來很酷,但如果您不是專業用戶,請不要這樣做

Windows 2000、Windows NT 4.0 和Windows NT 3.51
Windows 95、Windows 98 和Windows Millennium Edition
MS-DOS 或 Windows 3.x

=== 預防措施 ===
在創建包含Windows XP 和另一個操作系統的多重引導配置之前，請查看下列預防措施：

一定要備份當前的系統和所有的數據文件。
每個操作系統都必須安裝在一個單獨的捲上。 Microsoft 不支持在同一個卷上安裝多個操作系統。
如果計算機上只有一個卷，那麼，除非只是簡單地安裝Windows XP 的另一個副本，否則在開始創建多重引導配置之前，必須對硬盤重新進行格式化和分區以包含多個卷。
請不要在不是用NTFS 壓縮工具壓縮的壓縮驅動器上安裝Windows XP。

在安裝Windows XP 之前，應當關閉防病毒軟件，而且您可能希望運行Windows Memory Diagnostic 工具以測試計算機的隨機存取存儲器(RAM)。在安裝Windows XP 之後，確保重新啟用病毒防護軟件。
如果計算機位於Windows 2000 或Windows XP 域中，那麼必須對每個操作系統使用不同的計算機名稱。
應當按照從舊到新的順序安裝操作系統。如有可能，請按照以下順序安裝操作系統：
　MS-DOS
Windows 95、Windows 98 或Windows Millennium Edition
注意：不能在任何版本的Windows NT 之上安裝Windows Millennium Edition，但是它們可以在單個系統上共存。建議您將每個操作系統安裝到單獨的硬盤或分區上。如果已經裝有Windows NT，那麼Windows Millennium Edition 安裝程序會將其自身添加到Windows NT 啟動菜單中，從而允許您在Windows Millennium Edition 和Windows NT 之間進行多重引導。
Windows NT
Windows 2000
Windows XP（Professional 或 Home Edition）

=== 對硬盤進行分區以及選擇文件系統 ===
分區是硬盤的邏輯部分。每個分區通常都有自己的文件系統。
在以下情況下，您可能需要對硬盤重新格式化並重新進行分區：

只有一個卷，但是希望設置一個多重引導配置。必須在單獨的捲上安裝各個操作系統，以便每個安裝都可以保留其自身的文件和配置信息。
未使用正確的文件系統對啟動捲進行格式化：
如果希望使用Windows 95、Windows 98 或Windows Millennium Edition 與Microsoft Windows XP 一起創建多重引導系統，那麼必須使用FAT 對啟動捲進行格式化，這是由於Windows 95、Windows 98 和Windows Millennium Edition 不支持NTFS 文件系統。
如果您希望安裝Windows 95（零售版本4.00.950），那麼必須將啟動卷格式化為FAT。 Windows 95（OSR2.1 和更高版本）可以有一個FAT32 啟動卷，並可以與Windows 2000 和Windows XP 進行雙重引導。有關詳細信息，請參閱Microsoft 知識庫文章258662。
如果您希望使用Windows 95 OSR2、Windows 98 或Windows Millennium Edition 與Windows 2000 或Windows XP 一起創建多重引導系統，那麼可以使用FAT32 對啟動捲進行格式化。
注意：如果您使用NTFS 以外的任何文件系統格式化Windows NT 4.0、Windows 2000 或Windows XP 卷，那麼將會丟失所有NTFS 特有的功能。這包括文件系統安全性、加密文件系統(EFS) 設置、磁盤配額和遠程存儲等Windows XP 功能。同樣，Windows 95、Windows 98 和Windows Millennium Edition 無法識別NTFS 分區；它們將NTFS 分區識別為未知分區。因此，如果將Windows 98 或Windows Millennium Edition 分區格式化為FAT，而將Windows XP 分區格式化為NTFS，那麼在運行Windows 98 或Windows Millennium Edition 時，NTFS 分區上的所有文件都將不可用或不可見。

==== 不同操作系統對不同文件系統的支持度 ====

=== 用Windows XP 和MS-DOS、Windows 95、Windows 98 或Windows Millennium Edition 創建多重引導系統： ===
在多重引導配置中不能安裝下列操作系統中的某兩個或多個：Windows 95、Windows 98 和Windows Millennium Edition。
下列組合有效：

MS-DOS、Windows 95 和 Windows XP
MS-DOS、Windows 98 或Windows Millennium Edition 以及Windows XP
以下組合無效：

Windows 95、Windows 98 和Windows Millennium Edition
只有在安裝了MS-DOS、Windows 95、Windows 98 或Windows Millennium Edition 之後，才應當安裝Windows XP。這將防止這些操作系統覆蓋Windows XP 啟動扇區和Windows XP 啟動文件。
注意：如果操作系統的安裝順序有誤，那麼需要使用故障恢復控制台或者再次運行Windows XP 安裝程序才能返回到Windows XP。

=== 用Windows XP 和MS-DOS、Windows 95、Windows 98 或Windows Millennium Edition 創建多重引導系統： ===
確保要安裝的每個操作系統都有一個單獨的分區或硬​​盤，同時確保每個分區或硬盤都用正確的文件系統進行了格式化。
執行下列步驟之一：

如果希望創建一個MS-DOS、Windows 95、Windows 98 或Windows Millennium Edition 與Windows XP 共存的多重引導系統，那麼請首先安裝MS-DOS，然後安裝Windows 95、Windows 98 或Windows Millennium Edition，最後安裝Windows XP。
如果希望創建一個只包含Windows 95、Windows 98 或Windows Millennium Edition 的雙重引導系統，那麼請首先安裝Windows 95、Windows 98 或Windows Millennium Edition，然後安裝Windows XP。
按照標準安裝過程安裝每個操作系統。

=== 用Windows NT 4.0 和Windows XP 創建多重引導系統 ===
不建議您將包含Windows NT 4.0 和Windows XP 的多重引導系統作為一種長期解決方案。 Windows NT 4.0 Service Pack 5 (SP5) 中的NTFS 更新只是用來幫助您評估和升級到Windows XP。

確保硬盤已經用正確的文件系統進行了格式化：FAT32 或NTFS。
安裝Windows NT 4.0，從Microsoft 下載Windows NT Service Pack 5，並安裝該Service Pack。然後將Windows XP 安裝到一個單獨的捲上。
按照標準安裝過程安裝每個操作系統。
注意：如果您打算安裝的多個操作系統中只包括由Windows NT 4.0 與Windows 2000 或Windows XP 構成的某種組合，那麼必須確保為Windows NT 4.0 安裝Service Pack 5 或更高版本。

Windows XP 自動將它在系統上找到的任何NTFS 分區升級到Windows 2000 和Windows XP 中所使用的NTFS 版本。但是，如果某個卷是使用Windows 2000 和Windows XP 中所用的NTFS 版本進行格式化的，那麼Windows NT 4.0 需要Service Pack 5 才能在該卷上讀取和寫入文件。

=== 指定啟動的默認操作系統 ===
如果您的計算機上有多個操作系統，那麼可以將您希望使用的操作系統設置為啟動計算機時的默認操作系統：

單擊“開始”、“控制面板”，然後雙擊“系統”。
在“高級”選項卡上，打開“啟動和故障恢復”下的“設置”。
在“系統啟動”下的“默認操作系統”列表中，單擊您希望在打開計算機時啟動的操作系統。
選中“顯示操作系統列表的時間”複選框，然後鍵入希望在啟動默認操作系統之前顯示列表的秒數。
警告：計算機上操作系統的數量和順序由啟動選項文件(Boot.ini) 控制。要手動編輯此文件，請單擊“啟動和故障恢復”選項卡上的“編輯”。在修改啟動選項文件時，一定要小心。錯誤地修改此文件可能會導致計算機無法使用。

=== 對多重引導系統的問題進行疑難解答 ===

==== Internet Explorer 錯誤： ====
在啟動Microsoft Internet Explorer 時，瀏覽器可能退出，您可能會看到一個類似如下內容的錯誤消息：
 iexplore caused an Invalid Page Fault in module kernel32.dll
如果您在單個卷上安裝了多個操作系統，那麼就可能出現此錯誤。要解決此問題，請將各個操作系統安裝到單獨的捲上。

==== 不能將計算機配置為啟動Windows 95 和Windows 98（或Windows Millennium Edition） ====
不能將計算機配置為在Windows 95 和Windows 98（或Windows Millennium Edition）之間進行雙重引導，因為這些平台使用相同的啟動文件。因此，不支持在Windows 95、Windows 98 和Windows Millennium Edition 之間進行多重引導。

==== 在啟動時不顯示啟動菜單 ====
在啟動計算機時，啟動菜單不顯示，並且您無法啟動Windows XP。如果您在安裝Windows XP 之後安裝了Windows 95、Windows 98 或Windows Millennium Edition，那麼就可能出現此問題。要解決此問題，請修復或重新安裝Windows XP。

== 修復或恢復系統 ==
可以通過多種不同的方法來修復或恢復系統。下面列出了各種方法的說明。請按如下順序嘗試使用這些方法：

還原到“最後一次正確”的配置。
在安全模式下啟動計算機並嘗試修復該問題。
使用 Windows XP 故障恢復控制台。
使用“系統還原”。
使用“自動系統故障恢復”（僅適用於Windows XP Professional，不適用於Windows XP Home Edition）。

=== 使用“最後一次正確”的配置： ===
如果Windows XP 無法啟動，那麼可以將系統還原到“最後一次正確”的配置（換句話說，可正常運行的最新設置）。下面是操作方法：

啟動計算機，然後在Windows 開始啟動時按F8。此時出現“Windows 高級選項”菜單。
使用箭頭鍵選擇“最後一次正確的配置（您的起作用的最近設置）”，然後按Enter。
如果出現啟動菜單，那麼請使用箭頭鍵選擇“Microsoft Windows XP”，然後按Enter。 Windows XP 即會將計算機還原到最近的還原點。

=== 使用Windows XP 故障恢復控制台： ===
Windows XP 故障恢復控制台允許您：

使用、複製、重命名或替換操作系統文件和文件夾。
在下次啟動計算機時啟用或禁用服務或設備啟動功能。
修復文件系統的引導扇區或主啟動記錄(MBR)。
創建和格式化驅動器上的分區。
下面介紹如何使用故障恢復控制台：

將Windows XP CD 插入到CD-ROM ​​驅動器中，然後重新啟動計算機。
在出現的菜單上，單擊“安裝Microsoft Windows XP”。
按 R 修復所選的 Windows 安裝。
在使用故障恢復控制台時，系統將提示您輸入Administrator 帳戶的密碼。 如果您三次輸入錯誤的密碼，那麼故障恢復控制台將關閉。如果包含計算機的用戶帳戶信息的數據庫丟失或損壞，那麼您將無法使用故障恢復控制台。
在輸入密碼且故障恢復控制台啟動之後，鍵入exit 重新啟動計算機。故障恢復控制台有一些其他限制。

=== 使用“系統還原” ===
下一部分介紹如何使用“系統還原”工具將計算機返回到先前的工作狀態。 “系統還原”對關鍵系統文件和某些程序文件做一次“快照”，並將這些信息存儲為還原點。您可以利用這些還原點使Windows XP 返回到先前的狀態。

==== 創建還原點 ====
當您預計到對計算機進行的更改是危險的或者可能使計算機變得不穩定時，創建​​還原點將十分有用。

要訪問“系統還原嚮導”，請單擊“開始”，然後單擊“幫助和支持”。依次單擊“性能和維護”、“使用'系統還原'來撤消更改”以及“使用系統還原嚮導”。
單擊“創建一個還原點”，然後單擊“下一步”。
在“還原點描述”框中，鍵入一個名稱來標識該還原點。 “系統還原”會自動將創建該還原點的日期和時間添加到此名稱中。
要完成該還原點的創建，請單擊“創建”。

==== 使用“系統還原”來還原Windows XP ====
如果Windows XP 可以啟動，那麼可以使用“系統還原”將系統重新設置為以前的工作點。下面是操作方法：

以管理員身份登錄 Windows。
單擊“開始”，指向“所有程序”，指向“附件”，再指向“系統工具”，然後單擊“系統還原”。 “系統還原”即會啟動。
在“歡迎使用系統還原”頁面上，單擊“恢復我的計算機到一個較早的時間”（如果尚未被選中的話），然後單擊“下一步”。
在“選擇一個還原點”頁面上，單擊“在列表中，單擊一個還原點”列表中最近的系統檢查點，然後單擊“下一步”。此時可能出現一條“系統還原”消息，列出“系統還原”將進行的配置更改。單擊“確定”。
在“確認還原點選擇”頁面上，單擊“下一步”。 “系統還原”會還原以前的Windows XP 配置，然後重新啟動計算機。
以管理員身份登錄計算機。此時會出現“系統還原”的“恢復完成”頁面。單擊“確定”。

=== 使用“自動系統故障恢復”： ===
我們建議您定期創建備份，並將其作為系統故障恢復整體規劃的一部分。
注意：從備份中還原應當是系統故障恢復的最後一種方法。只有在其他選項都嘗試過之後才應使用此方法。例如，您應當首先嘗試在安全模式下啟動計算機並還原到“最後一次正確”的配置。這些步驟已在此部分的前面介紹過。
“自動系統故障恢復”(ASR) 系統分為兩部分；包括ASR 備份和ASR 還原。 ASR 嚮導（位於“開始”菜單上的“附件”\“系統工具”\“備份”下）執行備份部分。該嚮導備份系統狀態、系統服務以及與操作系統組件相關的全部磁盤。 ASR 還會創建一個文件，其中包含有關備份、磁盤配置（包括基本捲和動態卷）以及如何完成還原的信息。
在安裝過程的文本模式部分中出現提示時，可以按F2 訪問還原部分。 ASR 從它所創建的文件中讀取磁盤配置。它會還原磁盤上啟動計算機所必需的全部磁盤簽名、捲和分區。 ASR 將嘗試還原全部磁盤配置，但在某些情況下，它可能無法這樣做。然後，ASR 會安裝Windows 簡裝版，並使用由ASR 嚮導創建的備份自動開始還原
